存档和同盟分享

您输入的盟主名称、同盟名称，以及游戏生成的成员、武将、阵容、战法、城池进度、玉币、皮肤和设置，保存在手机的应用数据区，用于继续游戏和恢复已解锁的内容。您可以使用自选昵称。核心玩法支持离线游玩，无需向开发者注册账号。

您点「复制同盟码」时，游戏把同盟名称以及各成员的武将、进阶、站位和战法预设编码，写入系统剪贴板，并读取一次以核对复制结果。导入对手时，点「粘贴」才会读取剪贴板，也可以自行在输入框填写。将分享码发给他人后，对方可以导入这些资料。请避免在同盟名称中填写真实姓名等个人信息。

自愿观看激励广告

从备战行营或地图点玉币旁的「＋」会打开说明页。只有主动点「自愿观看」后，游戏才请求启动 Tosin 广告服务。您可以在说明页返回；加载失败时可以继续游戏。建盟、攻城、推进天下大势和赛季结算均可获得玉币。

为把奖励记入正确存档，游戏向广告服务商提交随机生成的存档标识和本次请求编号。广告平台核验后，游戏在本机记录回执和已发奖的编号，向本存档盟主发放 20,000 玉币。这些编号用于关联请求和防止重复发奖。游戏不随广告请求提交您的同盟名、盟主名、阵容或完整存档。

广告功能使用联网和查看网络连接状态的权限。请求广告时，服务商可获得连接的 IP 地址，并可能处理设备型号、系统版本、屏幕参数、网络类型、运营商、应用包名及版本、广告展示、点击、播放、关闭、转化和错误诊断记录。部分互动素材可能使用加速度或陀螺仪等传感器信号。具体接收方取决于本次广告来源。

广告渠道组件还声明了振动、保持唤醒及调整任务顺序等能力，分别用于互动反馈、播放和界面切换。游戏通过 Tosin 接口关闭个性化广告，并将定位、电话状态、已安装应用列表、Android ID、OAID、Wi-Fi 状态、MAC 地址、外部存储写入和录音的访问开关设为禁止。第三方政策同时介绍其 SDK 在其他配置下支持的能力。您可在系统应用设置中查看本机实际授予的权限。

信息的保存、反馈与保护

本机存档与设置保留至覆盖或删除。奖励记录分别保存在相应存档和应用的本地回执记录中，用于补发和去重。开发者未提供云存档。服务商持有的广告记录按各自政策列出的期限或必要期间保存，您可向服务商查询，也可联系开发者协助处理。

主动发邮件反馈时，开发者和邮件服务商会收到您的发件地址、邮件正文及您选择附上的材料。请遮盖与问题无关的信息。开发者仅在处理来信和必要复核期间保存反馈，在目的完成后删除或匿名化，依法需要继续保存的部分仅保留至规定期限。

开发者在中国境内处理收到的反馈，并限制对邮箱和反馈资料的访问。如需向境外提供个人信息，将依法说明接收方、用途和权利行使方式并履行适用手续。若发生个人信息安全事件，将及时补救，并按要求报告及通知受影响的玩家。

查阅、删除和撤回选择

在游戏的「存档」页面可载入或删除指定存档。删除该档会移除它的进度与解锁记录。要清除全部本机资料，可打开手机「设置 → 应用 → 三国：我来当盟主 → 存储 → 清除数据」。系统菜单名称可能略有差异。请先确认要保留的进度和副本。

您可以随时停止选择观看广告。加载中返回会取消本次加载。要结束已启动的广告组件，可退出并在系统应用设置中强行停止游戏。清除本机数据仅作用于本设备；如需查询或删除服务商的记录，可通过上方隐私政策或联系开发者办理。

您可通过 1900502733@qq.com 申请查阅、复制、更正、补充、删除信息，撤回同意、限制处理或请求解释。请说明涉及的功能和大致时间。开发者仅在核验所需范围内请求补充资料，于十五个工作日内回复；如无法满足申请，会说明原因。您也可以依法投诉或寻求司法救济。

儿童及监护人的选择

请未成年人在监护人指导下阅读本政策。不满十四周岁儿童的个人信息属于敏感个人信息。在取得监护人单独同意前，请勿观看激励广告或提交儿童的个人资料。监护人可以陪同儿童离线游玩，或代为联系开发者。

监护人可通过隐私邮箱申请查阅、更正或删除儿童信息。如发现未经监护人同意的处理，开发者将核实、停止相关处理，并删除相关信息或协助联系服务商删除。
