一 我们如何收集和使用信息

本机游戏数据

为实现继续游戏、保存和读取进度，本游戏在应用的本地存储空间中保存游戏状态，包括游戏内日期、势力与城池、资源、人才、部队、战斗和任务记录、随机状态、存档时间，以及自动存档、三个手动存档位、上一局和恢复备份。声音开关等偏好也在本机保存。这些数据用于恢复玩法与设置，游戏自身不将其与姓名、手机号或外部账号关联，也不上传给我们；TapPlay 对其运行环境及平台备份的处理见第五部分。

为适配画面和执行保存操作，游戏在本机使用屏幕尺寸、安全显示区域、触摸输入、系统时间等必要运行参数。系统或游戏引擎可能在本机产生错误诊断日志；本游戏没有自动日志上传或崩溃上报功能，也不据此建立用户画像。

您主动提供的反馈信息

您通过邮箱咨询、报告故障或提出隐私权利请求时，我们会收到发件邮箱、邮件显示名称、沟通内容，以及您主动附上的截图、游戏存档、设备型号或系统版本等资料。我们仅在答复、定位问题、处理请求及必要复核的范围内使用这些信息，不用于广告、营销或追踪。

请仅提供与问题相关的内容，并遮盖截图中无关的姓名、联系方式等个人信息。我们不要求您提供密码、身份证照片、金融账号等敏感信息；如确需额外资料，会说明用途和必要性，由您决定是否提供。不提供排查所必需的资料可能影响该问题的处理，但不影响您正常游玩。

当前版本不涉及的信息及权限

本游戏不设置游戏账号、实名认证或充值入口，不收集注册手机号、登录密码、真实姓名、身份证号码或支付记录；不读取通讯录、短信、通话记录、照片库或已安装应用列表，不采集定位信息、IMEI、IMSI、Android ID、OAID、MAC 地址等设备标识符。

当前由我们提供的安卓安装包未声明联网或其他安卓权限，不申请相机、麦克风、位置、电话、通讯录、通知、读取或写入外部存储权限。本地存档使用应用自身的存储空间。上述说明不代表 TapTap 宿主应用没有权限或联网行为；平台会按其服务和授权另行处理。游戏内部的虚拟钱粮和召唤消耗不涉及真实货币支付。

我们仅在具有相应合法依据时处理个人信息。未来如增加信息处理目的、方式、种类或 SDK，会先更新告知并依法取得所需同意；需要单独同意的，将单独征求，不以本政策作为对未知用途的概括授权。

二 我们如何保存信息

本地游戏数据通常随游玩更新，直至被相应存档操作覆盖或您清除对应数据。旧局、手动槽及恢复备份有独立用途，开始新游戏不等于删除全部旧记录。当前版本没有开发者云端备份，也未开启我们所提供安装包的安卓自动数据备份。TapPlay 平台若提供并启用存档备份，平台副本的保存与删除按其告知和设置执行，不因本地数据删除而必然同时删除。

您主动发送的反馈信息保存在联系邮箱及为处理该问题所需的工作资料中。保存期限以问题处理、请求答复及必要复核所需的最短时间为限；目的完成且无需继续保存后，我们会删除或匿名化处理。法律法规要求继续保存的，仅在规定期限内保存，并限制其他处理。

我们在中国境内处理收到的反馈资料，不主动向境外提供这些资料。本机数据的位置取决于您的设备所在地。平台服务、邮件收发及政策网页访问涉及相应服务商，其处理规则见第五部分。未来如由我们向境外提供个人信息，我们会依法履行告知、同意及其他必要程序。

三 Cookies 和同类技术

本游戏不内嵌浏览器页面，不使用 Cookies、网页信标或类似技术追踪您的身份、浏览行为或广告偏好。本地存档和声音偏好仅用于游戏运行，不用于跨应用追踪、个性化广告或商业推荐。

四 信息的共享 转移和公开披露

我们不出售您的个人信息，不向广告商或数据分析机构提供本地游戏数据或反馈资料，不为广告或营销委托第三方处理这些信息。本地存档不会由游戏自动向任何第三方传输。邮件收发所涉及的服务见第五部分。

如因处理您的具体请求确需向其他个人信息处理者提供信息，我们会告知接收方名称、联系方式、目的、方式及信息种类，并在依法需要时取得您的单独同意。依法必须提供信息时，仅按合法要求提供必要范围的信息。

如因运营主体变更等原因确需转移我们持有的个人信息，我们会告知接收方及其联系方式，要求接收方继续履行保护义务；改变原处理目的或方式时，依法重新取得同意。除取得您的单独同意或法律法规另有规定外，我们不公开披露您的个人信息。

五 第三方产品 服务和 SDK

当前游戏未集成用于登录、实名认证、防沉迷、广告、支付、统计分析或崩溃上报的第三方 SDK，也未接入 TapSDK。游戏使用 Godot 引擎在本机运行；本游戏未启用借助引擎向外部服务上传个人信息的功能。

TapTap 及其 TapPlay 服务由易玩（上海）网络科技有限公司提供。通过 TapPlay 运行《汉阙：天命召贤》时，平台负责其账号、实名认证及未成年人防沉迷服务，并可能按其规则处理账号信息、实名信息、设备与网络信息及使用记录。游戏未额外接入防沉迷 SDK，也不因此取得平台保存的真实姓名或身份证号码。请在使用平台服务前阅读 TapTap 的具体告知与隐私政策：TapTap 隐私政策 。

TapPlay 提供存档备份能力。若您使用的版本和平台设置开启了该服务，相关存档可能由平台备份、保留或恢复。是否提供及启用、保存期限、删除与恢复方式，以您使用时的平台具体说明和实际设置为准；您可向 TapTap 查询或提出管理请求。我们不会将平台备份描述为开发者自建云存档，也不承诺清除本地数据即可清除平台副本。

我们的联系邮箱为 QQ 邮箱。您发送反馈时，收发邮件服务商会为邮件传输、存储及安全保障处理邮件地址、内容和附件。QQ 邮箱服务由腾讯提供，其处理规则可在 QQ 邮箱的“隐私保护指引”中查阅；您使用的发件邮箱也适用其服务规则。该邮件服务不集成在游戏内，只有您主动发信时才涉及邮件交互。

本隐私政策的公开网页使用 GitHub Pages 托管。该网页不设信息收集表单，不加载广告或统计脚本，也不读取游戏存档。访问网页时，GitHub 会为安全目的记录访客 IP 地址；此为网页托管服务的信息处理，不代表离线游戏向其上传数据。详情见 GitHub 隐私声明：GitHub 隐私声明 。

六 我们如何保护信息

本游戏通过应用专用目录保存本地数据，使用存档完整性校验、临时写入和备份恢复措施降低意外损坏风险。完整性校验不等于加密，不能替代设备本身的访问保护。请妥善保管设备、设置锁屏保护，并谨慎向他人提供存档或诊断资料。

对您主动提供的反馈资料，我们将限制为处理请求所必需的访问与使用，妥善保护联系邮箱和工作设备，及时清理不再需要的信息。若发生个人信息安全事件，我们将及时采取补救措施，依法向相关部门报告，并在依法需要时通过邮箱或公告告知受影响用户、可能影响及可采取的防护措施。

七 您如何管理信息

查看和删除本地游戏数据

您可以通过开始界面的“继续”“存档”，或游戏内“设置—存档”读取已保存的进度，通过设置调整声音。当前游戏没有账号资料页，也没有单独删除所有存档的游戏内按钮。

独立安装的安卓版本，可在系统“设置—应用—汉阙：天命召贤—存储”中选择“清除数据”或“清除存储空间”，不同设备名称可能不同；仅清除缓存不能替代清除应用数据。通过 TapPlay 运行时，请使用平台实际提供的本游戏数据管理方式；如找不到对应入口，请联系 TapTap 客服，避免为了删除本游戏记录而误清除整个 TapTap 的其他数据。

清除对应的游戏本地数据会删除进度、手动槽、自动存档、上一局、恢复备份和声音设置，我们没有开发者云端副本可用于找回。我们不能远程访问或删除您的本机数据。如您使用了 TapPlay 平台备份或另行制作的备份，还需按相应方式单独管理或删除，平台副本不保证随本地数据一并删除。

管理向我们提供的信息

您可向 1900502733@qq.com 提出查阅、复制、更正、补充、删除个人信息、撤回同意或限制处理的请求，也可以请求我们解释本政策。符合法定条件的信息转移请求，我们将依法协助。请描述相关邮件或事项，我们仅核对处理请求所必需的信息，不要求提供无关身份证明。

我们将在收到请求后十五个工作日内答复。撤回同意不影响此前依法进行的处理；撤回后，我们将停止相应处理，并依法删除不再需要的信息。确因法律规定不能立即删除时，我们会说明原因，并停止除必要存储和安全保护之外的处理。对不能满足的请求，我们会说明理由及可用的救济途径。合理的权利请求不收取费用。

当前版本没有注册或登录账号，因此不存在游戏账号注销流程。您无需向我们申请注销即可停止使用或清除本机数据；TapTap 等第三方账号的注销应通过相应平台办理。

八 未成年人个人信息保护

如您未满十八周岁，请与父母或其他监护人共同阅读本政策，并在监护人的指导下使用游戏。通过 TapPlay 游玩时，应遵守平台实名认证和未成年人防沉迷要求；相关实名信息由平台依其规则处理，本游戏自身不向您索取身份证件等实名资料。

我们不主动收集不满十四周岁未成年人的个人信息。未满十四周岁的用户如需反馈问题，请由监护人代为联系，并避免提交儿童姓名、照片、证件等资料。如发现收到不应保留的儿童个人信息，我们会及时删除；如确需处理，将依法取得监护人同意并适用专门的儿童个人信息保护规则。监护人可通过本政策邮箱提出查询或删除请求。

九 本政策如何更新

我们会在本政策发布页面更新内容，并标明更新及生效日期。涉及信息处理目的、方式、种类、第三方接收方或联系方式等重要变化时，将通过游戏发布页面公告等显著方式告知，并在相关处理开始前依法取得所需同意。政策更新不会被视为您对新增信息处理的自动同意。

我们会保留历史版本供查询，您可以通过联系邮箱索取。新增联网、账号、广告、付费、实名核验或 SDK 功能时，应以对应新版本的实际告知为准，当前政策不表示这些功能已经提供。
