一、本机存档和设置

游戏将势力、人才、资源、军团、战斗进度、存档时间、人才自定义属性和游戏设置保存在应用专用空间，以便您继续游玩。本机还保存跨存档共用的激励奖励账本，记录领取、使用及待核验的奖励。开始新局后，已有账本继续使用。

开发者不提供云存档，也不自动接收您的完整存档。游戏使用屏幕尺寸、触摸操作和系统时间来适配界面和保存进度。游戏不设真实货币充值入口，无需向开发者提供姓名、身份证号、手机号或支付账户。

二、选择观看激励广告时

每次运行中，首次选择观看时会显示“自愿广告赞助”。点“暂不观看”会返回游戏；点“同意并观看”后，游戏的广告桥接才会主动初始化 Tosin 并请求广告。本次运行记住您的选择，后续仍由您主动发起观看。弹窗里的“隐私政策”可查阅 Tosin 的说明。

为下载和播放素材、统计展示效果、核验奖励、识别作弊和排查故障，Tosin 及实际提供广告的合作方可能直接取得以下信息。

  • 设备与联网信息。设备品牌、型号、系统版本、屏幕参数、语言、时区、处理器和存储容量，以及 IP 地址、运营商、网络类型和连接状态。
  • 应用与广告使用记录。包名、版本、应用运行状态，广告展示、播放、点击、关闭及转化记录，错误、崩溃和性能数据。
  • 互动与防作弊信息。广告组件可能读取加速度、线性加速度、陀螺仪、磁场、旋转矢量及重力传感器数据。此类读取在 Android 上可能没有单独的系统权限弹窗。

奖励如何对应到本机。游戏向 Tosin 传入本机生成的随机奖励账本标识和本次请求标识，接收奖励核验结果及广告方返回的订单标识。它们用于将奖励发给正确的账本、恢复待处理回执并避免重复发放。同一账本下的奖励可以关联。游戏不会把整份存档交给广告方。

个性化广告与权限。游戏通过 Tosin 接口关闭个性化广告，并将定位、应用安装列表、电话状态、Android ID、开放匿名设备标识符（OAID）、Wi-Fi 状态、MAC 地址、外部存储写入和录音九项访问开关设为不允许。广告服务商通用政策中还会列出其 SDK 支持的设备标识和其他能力。上面的设置是本版本向聚合 SDK 传达的限制。

安装包声明了联网、查看网络连接、振动、保持设备唤醒和调整任务顺序等权限，另含厂商标识服务及组件通信声明。游戏不申请定位、电话、录音、相机、通讯录、短信或外部存储权限。观看非个性化广告仍需要联网，广告服务商会获得该次连接的 IP 地址。

五、信息保存与保护

本机存档和设置通常保留至覆盖或清除，奖励回执按核验与防止重复发奖的需要保留在本机账本中。广告服务商持有的投放、反作弊和诊断记录由其按上述政策保存。您可直接联系相应服务商，也可请我们协助查询保存期限或申请删除。

开发者在中国境内处理收到的反馈，仅在答复、解决问题和必要复核所需的最短期间保存；目的完成后删除或匿名化，依法需要继续保存的部分在规定期限内限制使用。若今后需要由开发者向境外提供个人信息，将依法履行告知、单独同意等适用程序。

我们限制对反馈资料的访问，保护联系邮箱与处理设备。发生个人信息安全事件时，将采取补救措施，并按法律要求报告及告知受影响的玩家。

  • 管理本机数据。您可以在游戏中查看存档与设置。在 Android 的“设置 → 应用 → 三国：天命召贤2 → 存储”中选择“清除数据”会同时删除本机进度、人才设置和奖励账本，这些数据可能无法恢复。不同设备的菜单名称可能略有不同。若您另有平台备份，请在该平台管理副本。

七、未成年人和监护人

请未成年人在监护人指导下阅读本政策。不满十四周岁玩家的个人信息属于敏感个人信息。涉及此类信息时，应当事先取得监护人单独同意。当前游戏未设广告观看者年龄验证；未取得监护人单独同意的，请选择“暂不观看”，反馈问题请由监护人代为联系。

监护人可代表儿童申请查阅、更正或删除信息。若发现儿童在未获授权的情况下观看广告或提交资料，请联系隐私邮箱，说明大致时间和涉及的功能。我们会核实、停止相关处理，并删除或协助广告服务商删除有关信息。
